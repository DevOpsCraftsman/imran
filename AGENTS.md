# Agent Instructions - Imran Project

This project is a static website for Imran, deployed on **Render**.

## Deployment Strategy
- The project is configured for **Auto-deployment on Push**.
- **Mandate:** After every functional change or iteration, you MUST:
  1. `git add` the changes.
  2. `git commit` with a descriptive message.
  3. `git push origin main` to trigger the automatic deployment on Render.

## Tech Stack
- Static HTML5 / CSS3 / Vanilla JS.
- Deployment: Render (Static Site).
- Repository: GitHub (DevOpsCraftsman/imran).

## Context
- The site is in Arabic (`dir="rtl"`).
- Main sections: Welcome page (`index.html`) and Arabic Vocabulary Quiz (`quiz.html`).
