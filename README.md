# Site Web d'Imran 🌟

Petit site statique personnel pour mon fils Imran.

## Technologies
- HTML5 / CSS3 (Animation d'étoiles, gradients)
- Déploiement : [Render](https://render.com) (Static Site)

## Déploiement
Le projet est configuré avec un fichier `render.yaml` pour un déploiement automatique en tant que **Static Site**.

### Instructions pour Render
1. Connectez-vous à votre tableau de bord Render.
2. Cliquez sur **New** -> **Blueprint**.
3. Sélectionnez le dépôt `DevOpsCraftsman/imran`.
4. Render détectera automatiquement le fichier `render.yaml` et configurera le service.
